# Amazon Clone — E-commerce Website

A front-end e-commerce practice project inspired by Amazon, built to strengthen my JavaScript skills through practical web development.

## About the Project

This project recreates key features of an online shopping experience. It helped me move beyond learning JavaScript concepts individually and apply them in a larger application where different components work together.

The project uses the SuperSimpleDev API for product and order data.

## Features

- **Product Display:** Displays products and their information.
- **Shopping Cart:** Add products to the cart and update cart quantities.
- **Checkout:** Review cart items and proceed through the checkout flow.
- **Delivery Options:** Select delivery options during checkout.
- **Order Summary:** View products, quantities, prices, and order totals.
- **Order History:** View previous orders.
- **Tracking Page:** View estimated delivery information and a time-based delivery progress indicator.

## Technologies Used

- HTML
- CSS
- JavaScript
- SuperSimpleDev API

## Challenges and Problem-Solving

One of the interesting challenges was implementing the order tracking page. I had to work with order dates, estimated delivery dates, and elapsed time to calculate a progress indicator.

I also encountered bugs during development that required me to investigate the cause, review how my functions interacted, and correct the underlying logic.

These experiences helped me understand that programming involves more than writing code. It also requires testing, debugging, and understanding how an application behaves.

## Getting Started

To run the project locally:

1. Clone this repository:

   ```bash
   git clone YOUR_REPOSITORY_URL
   ```

2. Open the project folder in your code editor.

3. Run the project using your preferred local development server or the setup required by the project.

4. Explore the product, cart, checkout, order history, and tracking pages.

**Note:** Some features depend on the SuperSimpleDev API being available. Check the project's configuration for any additional setup requirements.
